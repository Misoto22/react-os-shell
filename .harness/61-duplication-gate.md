# DUPLICATION GATE — the jscpd ratchet

P1 migration source: efficient-shop `doc/duplication-gate.md` (kept
authoritative there until moved).

- DUP-1 — CI fails when copy-paste duplication INCREASES (jscpd tokens vs a
  committed baseline). Existing duplication is grandfathered, triaged, and
  burned down by card. **Enforced** in shop; rollout order P3: dealer →
  admin → pos → the rest.
- DUP-2 — The gate is textual-only; semantic duplication (same concept
  redrawn) is measured by survey (`dup-concepts`), never gated — a gate you
  cannot pass is a gate someone deletes.
- DUP-3 — No waiver lists on geometry gates (glyph single-home): an
  exception list goes green on the tenth copy.
